n8n, Zapier, Make or Claude Code: which automation tool suits a small business?

The short answer

Choose Zapier when non-technical staff need simple app-to-app automations quickly. Choose Make for visual multi-step scenarios at a lower entry price. Choose n8n when someone technical wants self-hosting or high volumes billed per run. Choose Claude Code when the work needs judgement, such as drafting a weekly report, and someone is comfortable working with files.

Zapier, Make and n8n run fixed workflows when something happens in one of your apps. Claude Code is an agent that writes and runs the work itself. This guide compares how each one charges and where your data sits, then matches each tool to the kind of team that gets the most from it.

01What are n8n, Zapier, Make and Claude Code?

A workflow automation tool is software that runs a fixed sequence of steps across your apps when a trigger fires, such as a new form entry going into your CRM. Zapier, Make and n8n are workflow automation tools. Claude Code is an agent: you give it instructions and it writes and runs the work.

The three workflow tools differ mostly in how they are built and billed. Zapier connects a very large catalogue of apps with a step-by-step builder; its pricing page describes Zapier MCP as connecting AI assistants to about 9,000 integrations1. Make gives you a visual canvas of modules called a scenario. n8n has a similar editor, runs on its cloud or your own server, and suits technical users who want code steps.

Claude Code comes from a different direction. Anthropic's documentation describes Claude Code as an agentic coding tool that reads your codebase, edits files, runs commands and integrates with your development tools, and says it can connect to tools such as Google Drive, Jira and Slack through MCP2. For a marketing team, the codebase can be a folder of briefs, voice rules and scripts. The pillar guide on what an AI marketing agent is explains the difference between an agent and a fixed automation in more depth.

02How does each tool charge?

Each tool counts usage differently. Zapier counts tasks, and every step and connector call uses them. Make counts credits, mostly one per action. n8n counts executions, one per full workflow run regardless of steps. Claude Code comes with a Claude subscription and draws on that plan's usage limits, with extra usage available at API rates.

The unit matters more than the headline price. Take a ten step workflow that runs 500 times a month:

  • Zapier's pricing page says every step in a Zap and every external connector call uses tasks, with rates that vary by AI model tier, code runtime and connector type, and that one Zapier MCP tool call uses two tasks1. That workflow could use thousands of tasks a month.
  • Make's pricing page says most actions consume one credit, and that a scenario can use anywhere from two credits to thousands in a single run3. Routers and error handlers use no credits.
  • n8n's pricing page defines an execution as a single run of your entire workflow, whatever the number of steps or the amount of data4. That workflow uses 500 executions.
  • Anthropic's pricing page says Claude Code is included in all paid plans and shares the same usage limits as the rest of the plan5. Heavy use can move to pay-as-you-go API credits.

Seats differ too. n8n says all its plans include unlimited users and workflows4. Zapier keeps shared Zaps, shared app connections and SAML SSO for its Team plan. Claude is priced per seat.

04Where does each tool win?

Zapier wins on breadth and speed for non-technical staff. Make wins when a visual, multi-branch workflow needs to run often at a low entry price. n8n wins on cost per run at volume and on self-hosting. Claude Code wins when the job needs judgement, such as reading several sources and drafting something a person then reviews.

In practice:

  • Zapier suits an office manager who wants each new website enquiry to land in the CRM and trigger a reply, set up in an afternoon.
  • Make suits an operations person who likes to see the whole flow on one canvas, with routers that send different records down different paths.
  • n8n suits a business with a developer or technical marketer, where workflows call internal systems or run thousands of times a month.
  • Claude Code suits recurring marketing work that changes each time: a weekly performance summary written from several exports, first drafts from a brief, or research on a list of accounts.

Many small businesses end up with two: one workflow tool for instant triggers between apps, and an agent for the work that needs reading and writing. The guide to AI marketing automation for small business lists the six automations most businesses should set up first, whichever tool runs them.

05Where does your data live, and can you self-host?

Only n8n can be fully self-hosted on servers you choose. Zapier stores data in the United States. Make lets you choose a US or EU data centre when you create the organisation. n8n Cloud stores data in Germany. Claude Code works on files on your machine and sends prompts to Anthropic, or a cloud provider you configure, for processing.

The vendors' own pages: Zapier's security page says Zapier stores data on Amazon Web Services in the United States8. Make's help centre says each organisation can choose a US or EU data centre, and the location cannot be changed after the organisation is created9. n8n's pricing FAQ says hosted plans store data in the EU on servers in Frankfurt, and self-hosted data sits wherever you host n8n4.

Self-hosting has terms and a cost. n8n's licence FAQ says that if workflows are only created or modified by you or people in your organisation, you can use the Community licence for free, and that hosting n8n as a service for clients to build workflows is not allowed under it10. n8n calls this licence fair-code and source-available. Its documentation also says self-hosting requires technical expertise, and that maintenance is your responsibility11.

For New Zealand businesses, the Office of the Privacy Commissioner says that in most circumstances you remain responsible for personal information you put in the cloud12, wherever the servers are. List the customer fields each workflow touches before you build it.

07Which tool suits your team?

Match the tool to the person who will own it. A non-technical owner or office manager should start with Zapier. An operations-minded person who enjoys building should try Make. A team with a developer, or with strict data needs, should look at n8n. A marketer comfortable with files who wants drafting and reporting done should look at Claude Code.

08When should you hire an n8n, Zapier or Make consultant?

Hire a consultant when an automation touches customer data or payments, or must keep running across several systems without anyone watching, and nobody on the team has the hours to learn the tool. Do it yourself when the workflow is simple and low risk, and someone on the team will own and maintain it.

Each vendor publishes a directory to start from. Zapier's directory lists Zapier Solution Partners with tier labels, ratings and reviews13. Make's Partner Directory describes its partners as certified Make experts, ranked Platinum, Gold and Silver14. n8n's Expert Partners page says the programme is a closed pilot, with a directory of pilot partners15.

Whoever you hire, ask for these in writing:

  1. A scope listing each workflow, its trigger, the apps it touches and the customer data it handles.
  2. Accounts, connections and API keys in your company's name, never the consultant's.
  3. Error alerts that go to a named person in your business.
  4. Documentation a new staff member could follow, plus a recorded walkthrough.
  5. A fixed price for the build, and a separate, optional price for maintenance.

The comparison of AI agencies, AI automation agencies and AI consultants covers how to vet providers more broadly, and the page on hiring a marketing automation consultant explains what a scoped automation build includes.

09What does maintenance cost?

Every automation needs upkeep. Apps change their connections, logins expire, usage grows past the plan and the person who built it leaves. Budget a few hours a month to check runs and fix errors, and expect the subscription to rise as volume grows. Self-hosted n8n adds server updates and backups to that list.

Know what happens at your limit before you hit it. Zapier's pricing page says that if you reach your task limit you are switched to pay-as-you-go unless you turn it off or move up a tier1. Make's pricing FAQ says scenarios stop running until credits are added again3. Either behaviour can surprise a busy team.

Claude Code needs a different kind of upkeep. Its instructions and skills drift as your business changes, and its output varies between runs, so a person reviews anything that reaches a customer. Rules that must hold every time belong in automated checks. A monthly routine covers most of it:

  • Review failed runs and error alerts, and fix the cause.
  • Check usage against the plan and the month before.
  • Reconnect any expired app connections.
  • Read a sample of agent output against your marketing automation rules and voice guide.
  • Update the documentation when a workflow changes.

11The short version

Zapier is the quickest start for non-technical staff, Make gives visual control at a lower entry price, n8n gives per-run billing and self-hosting for technical teams, and Claude Code handles marketing work that needs judgement. Pick the one the person who will own it can run.

Before you buy, price your real workflows in the tool's own billing unit. After you buy, keep every account in your company's name and set aside time each month for upkeep.

12Questions owners ask

Is n8n cheaper than Zapier?

Often, at higher volumes. n8n bills per workflow execution, one full run regardless of how many steps it has, and its Community edition is free to self-host for internal use. Zapier bills per task, and every step and connector call uses tasks. For a few simple two-step automations, Zapier's free and entry plans can cost less in money and in setup time.

How much does it cost to use Zapier?

Zapier's pricing page on 16 October 2026 listed a free plan with 100 tasks a month, Professional from US$19.99 a month billed yearly or US$29.99 monthly, and Team from US$69 a month billed yearly for 2,000 tasks. The price rises with the monthly task tier you choose, and Zapier offers billing in NZD and AUD.

Is n8n open source?

n8n describes its licence as fair-code, under its Sustainable Use License, and source-available. Its documentation says that if workflows are only created or modified by you or people in your organisation, you can use the self-hosted Community edition for free. Hosting n8n as a service for clients to build their own workflows needs a commercial licence.

What are companies like Zapier?

The closest alternatives are Make, which bills in credits for each action and has a visual scenario builder, and n8n, which bills per workflow run and can be self-hosted. Agent tools such as Claude Code sit in a different category: they write and run the work from instructions, which suits tasks that need judgement more than fixed rules.

Can Claude Code replace Zapier for a small business?

For some jobs. Claude Code can connect to tools through MCP, run on a schedule in the cloud and handle work that needs judgement, such as drafting a report from several sources. For instant app-to-app triggers, such as a new form entry going straight into a CRM, a workflow tool is usually simpler to run and hand over.

When should I hire an n8n, Zapier or Make consultant?

Hire one when an automation touches customer data or money, or must keep running across several systems without your attention, and nobody on the team has time to learn the tool. Ask for a written scope, accounts in your name, documentation and error alerts. All three vendors publish partner directories you can start from.
