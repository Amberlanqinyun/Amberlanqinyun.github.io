指南 / AI 营销智能体

n8n、Zapier、Make 还是 Claude Code：哪个自动化工具适合小企业？

简短回答

如果不懂技术的员工需要快速搭好简单的应用间自动化，选 Zapier。如果想用更低的入门价格做可视化的多步骤场景，选 Make。如果有懂技术的人想自托管，或者需要按运行次数计费来处理大量任务，选 n8n。如果工作需要判断，比如起草每周报告，而且有人习惯和文件打交道，选 Claude Code。

Zapier、Make 和 n8n 会在你的某个应用里发生特定事件时，运行固定的工作流。Claude Code 是一个智能体，自己编写并执行工作。这份指南比较每个工具怎么收费、你的数据存放在哪里，再把每个工具匹配给最能用好它的那类团队。

01n8n、Zapier、Make 和 Claude Code 分别是什么？

工作流自动化工具是这样一种软件：当触发条件出现时，它在你的各个应用之间运行一串固定的步骤，比如把新的表单提交送进 CRM。Zapier、Make 和 n8n 都是工作流自动化工具。Claude Code 是一个智能体：你给它指令，它来编写并执行工作。

三个工作流工具的区别主要在于构建方式和计费方式。Zapier 用逐步搭建的编辑器连接一个非常庞大的应用目录；它的价格页介绍，Zapier MCP 可以把 AI 助手连接到约 9,000 个集成1。Make 给你一块可视化画布，上面由模块组成的流程称为场景（scenario）。n8n 的编辑器与之类似，可以运行在它的云端或你自己的服务器上，适合想加入代码步骤的技术用户。

Claude Code 来自另一个方向。Anthropic 的文档把 Claude Code 描述为一款智能体编程工具，能读取代码库、编辑文件、运行命令，并与开发工具集成，还说明它可以通过 MCP 连接 Google Drive、Jira 和 Slack 等工具2。对营销团队来说，这个代码库可以是一个装着简报、语调规则和脚本的文件夹。什么是 AI 营销智能体这篇核心指南更深入地解释了智能体和固定自动化的区别。

02每个工具怎么收费？

每个工具计算用量的方式不同。Zapier 计任务，每个步骤和每次连接器调用都会消耗任务。Make 计额度，大多数操作消耗一个。n8n 计执行次数，一次完整的工作流运行算一次，不论有多少步骤。Claude Code 随 Claude 订阅提供，消耗该方案的用量上限，超出部分可以按 API 费率额外购买。

计费单位比标价更重要。以一个每月运行 500 次的十步工作流为例：

  • Zapier 的价格页说明，Zap 里的每个步骤和每次外部连接器调用都会消耗任务，消耗量因 AI 模型档位、代码运行时和连接器类型而异，一次 Zapier MCP 工具调用消耗两个任务1。这个工作流每月可能消耗数千个任务。
  • Make 的价格页说明，大多数操作消耗一个额度，一个场景单次运行可能消耗两个到数千个额度不等3。路由器（router）和错误处理器不消耗额度。
  • n8n 的价格页把一次执行定义为整个工作流的一次运行，不论步骤数量或数据量多少4。这个工作流消耗 500 次执行。
  • Anthropic 的价格页说明，所有付费方案都包含 Claude Code，并与方案中的其他功能共用同样的用量上限5。用量大时，可以改用按量付费的 API 额度。

席位规则也不一样。n8n 表示所有套餐都包含不限数量的用户和工作流4。Zapier 把共享 Zap、共享应用连接和 SAML SSO 留给 Team 套餐。Claude 按席位定价。

04每个工具的优势在哪里？

Zapier 的优势是覆盖面广，让不懂技术的员工也能快速上手。Make 的优势在于，以较低的入门价格频繁运行可视化的多分支工作流。n8n 的优势是在大用量时单次运行成本低，而且可以自托管。Claude Code 的优势在于需要判断的工作，比如读取多个来源，起草一份之后由人审核的内容。

放到实际工作里：

  • Zapier 适合这样的办公室经理：希望每条新的网站咨询都进入 CRM 并触发一条回复，一个下午就能设置好。
  • Make 适合喜欢在一块画布上看清整个流程的运营人员，可以用路由器把不同的记录送往不同的路径。
  • n8n 适合有开发人员或技术型营销人员的企业，工作流需要调用内部系统，或每月运行数千次。
  • Claude Code 适合每次都有变化的周期性营销工作：根据多份导出数据撰写每周表现总结，根据简报起草初稿，或者对一份客户名单做调研。

很多小企业最后会用两个：一个工作流工具负责应用之间的即时触发，一个智能体负责需要阅读和写作的工作。小企业 AI 营销自动化指南列出了大多数企业最先该设置的六项自动化，无论由哪个工具来运行。

05你的数据存放在哪里？能自托管吗？

只有 n8n 可以完全自托管在你选择的服务器上。Zapier 把数据存放在美国。Make 让你在创建组织时选择美国或欧盟的数据中心。n8n Cloud 把数据存放在德国。Claude Code 处理你电脑上的文件，并把提示词发送给 Anthropic，或你配置的云服务商来处理。

各供应商自己的页面：Zapier 的安全页面说明，Zapier 把数据存放在美国的亚马逊云服务（Amazon Web Services）上8。Make 帮助中心说明，每个组织可以选择美国或欧盟的数据中心，组织创建后位置无法更改9。n8n 的价格常见问题说明，托管套餐把数据存放在欧盟法兰克福的服务器上，自托管的数据则在你托管 n8n 的地方4。

自托管有条款，也有成本。n8n 的许可常见问题说明，如果工作流只由你或你所在组织的人创建或修改，就可以免费使用 Community 许可，但这一许可不允许把 n8n 作为服务托管给客户来构建工作流10。n8n 把这一许可称为 fair-code 和源代码可见（source-available）。它的文档还说明，自托管需要技术专长，维护由你自己负责11。

对新西兰企业来说，新西兰隐私专员办公室表示，在大多数情况下，你放到云端的个人信息仍由你负责12，无论服务器在哪里。在搭建每个工作流之前，先列出它会涉及的客户字段。

07哪个工具适合你的团队？

按将来负责它的那个人来匹配工具。不懂技术的企业主或办公室经理，应该从 Zapier 开始。喜欢动手搭建、有运营思维的人，应该试试 Make。有开发人员或数据要求严格的团队，应该看看 n8n。习惯和文件打交道、希望把起草和报告交出去的营销人员，应该看看 Claude Code。

08什么时候该请 n8n、Zapier 或 Make 顾问？

当一项自动化涉及客户数据或付款，或者必须在多个系统之间持续运行、没人盯着，而团队里又没人有时间学这个工具时，就请一位顾问。如果工作流简单、风险低，团队里也有人会负责并维护它，就自己来做。

每家供应商都公开了一份名录，可以从那里开始。Zapier 的名录列出了 Zapier 解决方案合作伙伴（Solution Partners），附有等级标签、评分和评价13。Make 的合作伙伴名录把合作伙伴介绍为经过认证的 Make 专家，分为白金、金牌和银牌三个等级14。n8n 的专家合作伙伴页面说明，这个计划是一个封闭试点，并附有试点合作伙伴名录15。

无论请谁，都要求对方书面提供以下内容：

  1. 一份范围说明，列出每个工作流、它的触发条件、涉及的应用和处理的客户数据。
  2. 账户、连接和 API 密钥都登记在你公司名下，绝不放在顾问名下。
  3. 错误提醒发送给你企业里一位指定的人。
  4. 一位新员工也能照着操作的文档，外加一段录制好的操作讲解。
  5. 搭建的固定价格，以及另行报价、可选的维护价格。

AI 代理机构、AI 自动化代理机构与 AI 顾问的对比更全面地讲了如何评估服务商，聘请营销自动化顾问的页面则介绍了一个范围明确的自动化搭建项目包含什么。

09维护要花多少钱？

每项自动化都需要维护。应用会更改连接方式，登录会过期，用量会超出套餐，搭建它的人也会离开。每月留出几个小时检查运行情况、修复错误，并预计订阅费会随着用量增长而上升。自托管的 n8n 还要在这份清单上加上服务器更新和备份。

在碰到上限之前，先弄清楚到时会发生什么。Zapier 的价格页说明，任务用量达到上限后，你会被切换到按量付费，除非你关闭这一选项或升级档位1。Make 的价格常见问题说明，场景会停止运行，直到重新添加额度3。这两种情况都可能让忙碌的团队措手不及。

Claude Code 需要的是另一种维护。它的指令和技能会随着业务变化而逐渐过时，每次运行的产出也不同，所以任何到达客户的内容都要由人审核。每次都必须遵守的规则，应当放进自动检查里。一套每月例行流程就能覆盖大部分工作：

  • 复查失败的运行和错误提醒，修复根本原因。
  • 对照套餐和上个月，检查用量。
  • 重新连接任何已过期的应用连接。
  • 抽读一部分智能体产出，对照你的营销自动化规则和语调指南检查。
  • 工作流有变化时，更新文档。

11简短版本

Zapier 是不懂技术的员工最快的起点，Make 以更低的入门价格提供可视化控制，n8n 为技术团队提供按运行次数计费和自托管，Claude Code 负责需要判断的营销工作。选择将来负责它的那个人能运行起来的那一个。

购买之前，用工具自己的计费单位为你真实的工作流算一下价格。购买之后，把每个账户都登记在你公司名下，并每月留出时间做维护。

12企业主常问的问题

n8n 比 Zapier 便宜吗？

用量较大时往往是。n8n 按工作流执行次数计费，一次完整运行算一次，不论包含多少步骤，它的 Community 版可以免费自托管供内部使用。Zapier 按任务（task）计费，每个步骤和每次连接器调用都会消耗任务。如果只是几个简单的两步自动化，Zapier 的免费和入门套餐在花费和设置时间上都可能更省。

用 Zapier 要花多少钱？

2026年10月16日，Zapier 价格页列出：免费套餐每月 100 个任务；Professional 按年付费每月 US$19.99 起，按月付费 US$29.99；Team 按年付费每月 US$69 起，含 2,000 个任务。价格随你选择的每月任务档位上升，Zapier 也支持用 NZD 和 AUD 付款。

n8n 是开源的吗？

n8n 把自己的许可称为 fair-code，采用其 Sustainable Use License，属于源代码可见（source-available）。它的文档说明，如果工作流只由你或你所在组织的人创建或修改，就可以免费使用自托管的 Community 版。把 n8n 作为服务托管给客户、让他们构建自己的工作流，则需要商业许可。

有哪些类似 Zapier 的工具？

最接近的替代品是 Make 和 n8n。Make 按每个操作消耗的额度（credit）计费，提供可视化的场景编辑器；n8n 按工作流运行次数计费，可以自托管。Claude Code 这类智能体工具属于另一个类别：它们根据指令编写并执行工作，更适合需要判断而不是固定规则的任务。

小企业可以用 Claude Code 替代 Zapier 吗？

部分工作可以。Claude Code 可以通过 MCP 连接工具，在云端按计划运行，处理需要判断的工作，比如根据多个来源起草一份报告。至于即时的应用间触发，比如新的表单提交直接进入 CRM，工作流工具通常更容易运行，也更容易交接。

什么时候该请 n8n、Zapier 或 Make 顾问？

当一项自动化涉及客户数据或资金，或者必须在多个系统之间持续运行而无需你照看，团队里又没人有时间学这个工具时，就请一位顾问。要求对方提供书面范围说明、登记在你名下的账户、文档和错误提醒。三家供应商都公开了合作伙伴名录，可以从那里开始找。
