案例研究

让答案引擎直接点名引用你。

geo-seo-claude 是一个以 GEO（生成式引擎优化）和 AEO（答案引擎优化）为先的 SEO（搜索引擎优化）工具包：可引用性评分、AI 爬虫访问分析、结构化数据（schema）标记生成，以及分析报告。

目标是被 ChatGPT、Claude 和 Perplexity 引用；Google 排名只是其中一项输入。已在 GitHub 公开，并在本站运行。作者 Amber Lan，AI 营销工程师。最后更新于2026年8月20日。

机会所在。

买家向 AI 助手寻求推荐，而 AI 助手会直接给出名字。

传统 SEO 的盲区

排名和外链无法说明 AI 爬虫能否访问网站，内容单独拿出来能否被引用，结构化数据有没有说清这家企业是谁。补上这块空白，小企业就能登上新的“首页”。

可以实际运行的检查

爬虫能否访问可以测试，结构化数据能否被解析也有明确结果，可引用性评分则需要写明标准。它必须作为一线从业者的工具在 Claude Code 中运行，在真实的客户网站上几分钟内出结果。

搭建内容。

工具包按答案引擎读取网站的方式来审计网站，再生成它所建议的修复方案。

爬虫访问

检查最关键的九个 AI 爬虫，从 GPTBot 到 PerplexityBot，以及 llms.txt 是否存在、质量如何。

结构

结构化数据的覆盖情况，以及答案先行的内容结构。

可引用性

段落级的可引用性评分，然后给出修复方案：robots 规则、JSON-LD 结构化数据，以及一份客户可以直接照着执行的报告。

关键决策。

三个判断，决定了先修什么。

以可引用性为指标

AI 回答摘取的，正是那些可以被引用的段落。给可引用性打分，会改变你优先修复的内容。

先解决爬虫访问，再处理内容

其他所有修复都以 GPTBot 和 PerplexityBot 能够进入网站为前提，所以审计从这里开始。

修复方案优先于问题清单

附上修正后的 robots.txt 和结构化数据代码块的报告，会被真正落实。一份问题清单，往往只会被归档。

结果。

证据就在眼前：本站运行的正是这套工具包自己的打法。

实时证据

flowai.co.nz 允许全部九个 AI 爬虫访问，在根目录和 .well-known 下都提供 llms.txt，每个页面都带有 JSON-LD，回答的结构也便于提取。Flow AI 的月度服务费（retainer）服务会把同一套工具包用在客户网站上。

佐证

在 GitHub 上查看工具包。查看线上实现：robots.txt、llms.txt，以及本页源代码中的结构化数据。
