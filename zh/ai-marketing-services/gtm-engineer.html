GTM 工程师搭建什么

从定位到销售管线之间的每一套系统。

每一套都运行在你自己的账户上，并配有文档，团队可以自行运转。

  • 目标客户名单

    根据你的定位确定值得触达的客户和决策人，并随市场变化持续更新。

  • 数据补全与评分

    在任何人发出第一封信之前，先把每个客户和联系人研究清楚并打分。

  • 主动外联

    由智能体起草个性化的第一条消息，经专人审核后通过 Apollo 和 HeyReach 发出。

  • CRM 架构

    从零搭建或重建 HubSpot：生命周期阶段、线索评分、分配与交接规则。

  • 自动化

    用 n8n、API 和 Claude Code 打通你已经在付费使用的工具，数据流转不再靠复制粘贴。

  • 销售管线报告

    归因分析，加上每周一份报告，把每一笔商机追溯到带来它的那项工作。

常见问题。

GTM 工程师做什么？

GTM 工程师搭建为销售输送机会的系统：目标客户名单、数据补全、主动外联序列、CRM 数据流，以及说明哪些工作带来销售管线的报告。营销工程师搭建产出营销内容的系统。Amber Lan 两者都做。

在新西兰能招到 GTM 工程师吗？

可以。Amber Lan 是常驻奥克兰的 GTM 工程师与 AI 营销工程师，欢迎新西兰、澳大利亚或远程团队的资深岗位机会，也接受项目和兼职合作。

GTM 工程师和 RevOps 有什么区别？

RevOps 负责贯穿营销、销售和客户成功的收入流程及其工具。GTM 工程师搭建并自动化其中产生销售管线的部分：名单、数据补全、主动外联，以及流入 CRM 的数据。在成长型团队里，往往由一个人兼顾两者。

Amber Lan 使用哪些工具？

HubSpot、Apollo、HeyReach、n8n、Zapier、Claude Code 和 MCP、基于 BigQuery 的 SQL、GA4 与 Google Tag Manager。所有搭建都在你自己的账户上进行，工具和数据都归你所有。

GTM 工程师可以兼职合作吗？

可以。兼职合作按每月固定天数进行，与你的团队一起运行并扩展这些系统，适合在需要全职岗位之前就需要系统的企业。
