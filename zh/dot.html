琥珀色的点，睁开了眼睛。

最早的标志是四个点，向上汇成一个琥珀色的点。这个琥珀色的点就是 Flow Intelligence：一颗玻璃球，光在它里面。它交代任务的智能体用同样的玻璃做成，各有一个柔和的形状，把这束光带进工作里。这一页讲的是这一家子、它们的物理，以及在本站驱动它们的引擎，和这里的一切一样开源。

物理

是什么让它有了生命感。

活物的动作是弹簧和眼跳，玻璃在接住光的地方才显出自己。八条规则，都很小，借自动画的基本功和玻璃的打光方式。

  1. 弹簧，而非缓动。 视线是一个阻尼弹簧（刚度 140，阻尼 18），会微微过冲再稳住，像真的眼睛。
  2. 眼跳。 没人理它时，每 1.5 到 4 秒选一个新点跳过去。眼睛从不漂移。
  3. 眼先动，身后随。 脸先朝视线方向挪，身体再通过一个更慢的弹簧跟着倾斜。这个延迟就是重量感。
  4. 为你睁开的眼睛。 静止时，眼睛是两道平静的弧线。你一来，或者有活要盯着，它就睁开眼：白色的眼睛，一颗大大的圆瞳孔朝你转过来，之后又安静地闭上。
  5. 透视。 向右看时，右眼缩小 6%，左眼放大 3%。扁平的形状变成了一颗头。
  6. 眨眼是一片眼睑。 眼睑从上方 70 毫秒合上，140 毫秒抬起，连续两次。合到底时，一道平静的弧线代替闭着的眼睛。
  7. 只打光，不描边。 身体和眼睛都没有描边。玻璃是半透明的，上沿接住光，顶部有一块柔和的高光，底部聚着暖光。Flow Intelligence 是同样的玻璃，琥珀色的光在里面。
  8. 挤压与拉伸。 呼吸时纵向拉伸 1.2%；点头时压扁到 90%，再经同一个弹簧恢复。

眼睛工作室

画眼睛的六种方法，一条规则管全部。点一个试试。

同样的玻璃、同样的物理。静止时是平静的弧线，专注时睁开眼睛，精确的时刻用一条平线。每只睁开的眼睛一样大，每条线（包括嘴）一样粗，所以这一家子看起来是一体的。

在本站，每张脸平时都是平静的弧线，有事需要它注意时才睁开眼睛；每个智能体用适合自己职责的那一组。

独一无二

眼睛让它成为一张脸，行为让它只属于这里。

谁都能画一个带眼睛的点。这些行为来自这套系统真正在做的事：读网站、给智能体交代任务、等人审核、在奥克兰的夜里工作。

01 · 双眨眼与轨迹

招牌眨眼，和它留下的轨迹。

人眨一次。这颗点快速眨两次，像相机确认对焦。而它每次移动，身后会留下标志的三个点，一瞬间就淡去：这个角色走到哪里，都带着品牌的轨迹。

02 · 逐行阅读

它一行一行地读。

工作时，眼睛从左扫到右，再换一行，像人读书一样。从外面看，AI 搜索审计就是这个样子。

03 · 害羞的一瞥

它看你，又移开，再看回来。

把指针放到它身上：它歪一下头，看你一眼，害羞地看向别处，再看回来，脸颊微微泛起琥珀色。聚焦输入框，它就看过去；打字时跟着光标。

04 · 点头

批准就是一个点头。

一次运行被批准时，身体往下一沉，眼睛笑起来。就像同事点一下头，没有对勾，也没有彩带。

05 · 奥克兰时间

它按你的作息。

奥克兰晚上十点到早上六点，网站上的点进入暗夜状态。地球另一边的访客看得到：你睡着时，它还在工作。

06 · 标志从哪里来

最早的标志是一条轨迹。

最早的标志是四个点，向上汇成一个琥珀色的点。把轨迹折起来，离琥珀点最近的两个奶白点就成了眼睛。这一家子的标志，就是从这张脸长出来的。

网站图标：那颗玻璃球，铺满边缘。

没有底板，没有深色边框，只有透明背景上的玻璃球，放在任何颜色的标签栏上都干净。眼睛比角色本身画得更大，16 像素时依然看得清；32 像素以上还能看到笑容。

以 favicon.svg 发布，另加一个 180 像素的 apple-touch-icon.png，琥珀色的光铺满整个图标，因为 iOS 会把透明的角涂成黑色。

辨认智能体

十个智能体，十种玻璃形状，各有各的脸。

颜色不用，所以身份都在形状和脸上。每个智能体的身体和眼睛都来自它的职责，一周之后，“最近”列表不看标签也能读懂。把指针放到任一智能体上：它看你一眼，再移开，像同事打个招呼。

以后新增的智能体先用一个带标准表情的玻璃圆，等它有了自己的形状再换：FlowDot.mount(el, {agent: 'new-agent'})。

// place a character with markup alone
<svg class="fdot" data-fdot="search" viewBox="0 0 100 100"></svg>   // or data-fdot="flow"

// Flow Intelligence, in the demo window status
var fi = FlowDot.mount(document.querySelector('#status svg'), { role: 'flow' });
fi.set('review');          // idle · think · work · review · done · late · error
fi.lookAt(0.2, -0.1);      // −1..1, overrides saccades until lookAt(null)
fi.nod();                  // on approve
fi.blink(true);            // double

// an agent, in Recents. Shape and face come from the agent map;
// agents the map does not know get a glass circle with the standard face.
FlowDot.mount(li.querySelector('svg'), { role: 'agent', agent: 'search' });

// the dark state follows Auckland time on its own
FlowDot.autoNight(fi);     // 22:00-06:00 Pacific/Auckland

    规则
    
    
    是什么让它温暖，并有别于企业吉祥物。
    
  
    
  
    
    
    永远
      
      
    • 两只眼睛和一张嘴，别无其他。 没有手臂、眉毛或帽子。表情来自眼睛、嘴和时机。
      • 
      
    • 一种材质。 Flow Intelligence 和每个智能体都是同样的玻璃。Flow Intelligence 把琥珀色的光装在里面；智能体把它带成底部的一汪暖光。
      • 
      
    • 只打光，不描边。 身体和眼睛都没有描边。边缘只在接住光的地方显出来。
      • 
      
    • 一条眼睛规则。 每只睁开的眼睛一样大：白色眼睛，一颗墨色瞳孔，没有高光。每条线形眼睛和每张嘴一样粗。
      • 
      
    • 处处柔和。 每个角都是圆的。弹簧与眼跳：没有滑动，双眨眼每 3 到 6 秒一次。
      • 
    
    
    
    绝不
      
      
    • 56 像素以下不用玻璃。 小尺寸的智能体换成实心奶白，脸依然看得清。
      • 
      
    • 没有第二种颜色。 智能体靠形状和脸区分，不靠颜色或衣服。
      • 
      
    • 不说话。 它永远没有对话气泡。演示窗口里的对话属于产品，不属于角色。
      • 
      
    • 没有悲伤状态。 失败表现为发懵的眼神和一张抖动的嘴。
      • 
      
    • 没有为动而动。 每个动画都标记一个真实状态：工作、等待、完成、离开。
